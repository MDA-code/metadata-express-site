IPTC metadata for sports photographers: what each field means

A 5-minute read.

IPTC metadata is the information stored inside a photo file: who shot it, who owns it, where it was taken and what's in it. Editors, wire services, agencies and photo platforms read it automatically, so filling it in correctly is what gets your photos credited, found and delivered to the right people.

It lives in two standard places inside each file (the older IPTC block and the newer XMP), and good software keeps them in step. Nothing here is specific to one program: any photo software that follows the IPTC standard reads the same fields.

Fill it in once with a template

Most of these fields are the same for a whole game, so type them once. In Metadata Express, open Session Setup → IPTC Template…, fill in what applies, and Save As… a named template (e.g. "Hawks Football"). It's written to every photo you tag, or to a whole folder at once with Apply to All Photos Now, and can be added automatically while importing.

  • Leave a field blank to keep whatever the photo already has. Metadata Express only changes the fields you fill in and never erases existing metadata or camera data.
  • The caption, keywords and Person Shown come from tagging, so the template doesn't need them.
  • Some older systems cut off long values (for example Byline at 32 characters); the template warns you when a field is over the IPTC limit.
