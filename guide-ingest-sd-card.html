How to import (ingest) photos from an SD card with an automatic backup

5 minutes to set up, then automatic.

"Importing" (often called ingesting by pros) means copying photos off the memory card onto your computer, ideally with sensible folder names, a backup copy and your copyright already written in. Doing it right on game day saves you from lost photos and from renaming files at midnight.

What a good import does

  • Copies only photos (RAW and JPEG, and video if you want it), from every folder on the card.
  • Checks every copy before counting it, and never overwrites a file that's already there.
  • Makes a second copy on another drive, so one failed drive never costs you a game.
  • Names folders and files consistently, e.g. 2026/2026-10-14 Hawks vs Tigers/2026-10-14_Hawks vs Tigers_001.ARW.
  • Only copies what's new when you plug the same card in again at halftime.

Step by step in Metadata Express

  1. Open Import / Cull from the home screen.
  2. Plug in your SD card. A window asks what to do: choose Import… (or Open in Cull to look through the card first and import just the shots you pick).
  3. Under From, your card is ticked. Tick several cards to import them together.
  4. Under To, pick your photo folder (for example Pictures), and set Folders inside it to something like {year}/{date} {event}. Type the event name in the Event box.
  5. Tick Rename the files if you want, e.g. {date}_{event}_{seq}. A RAW and its JPEG always keep the same name.
  6. Tick Also copy to a backup folder and choose a folder on a second drive.
  7. Pick your IPTC template so your byline, credit and copyright are written into every photo as it copies.
  8. Click Import. When it's done, the photos open in Cull, ready to pick.

The variables

VariableBecomes
{date}Capture date, e.g. 2026-10-14
{year} {month} {day}Parts of the capture date
{time}Capture time, e.g. 201033
{event}The event name you type, e.g. Hawks vs Tigers
{photographer}Your name
{camera}The camera model
{original}The camera's file name, e.g. DSC06437
{seq}A running number, e.g. 001, 002…

A / in the folder pattern makes a subfolder, so {year}/{date} {event} files each game under its year.

Quick selects during a break

Most cameras let you lock (protect) a photo with a button while reviewing it on the back screen. Tick Only photos locked on the camera and the import copies just those, so your best few shots are on the computer in seconds instead of waiting for 2,000 files. Turn on Import automatically and it starts the moment the card goes in.
